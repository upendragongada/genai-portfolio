
# AI-Powered eCommerce Search Engine

## Overview
A Python-based product search application designed
to demonstrate eCommerce search capabilities.

## Current Features
- Product catalogue using JSON
- Keyword-based product search
- Search result ranking
- Product category and price display
- Automated unit tests

## Technology Stack
- Python
- JSON
- Git and GitHub
- GitHub Codespaces

## Future Enhancements
- BM25 search
- OpenSearch integration
- Semantic search
- Vector embeddings
- Hybrid search
- FastAPI backend
- AI-powered product recommendations

## Running the Application

python src/main.py
